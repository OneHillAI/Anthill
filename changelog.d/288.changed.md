**The user guide now explains backup and restore.** It says that only the install owner can make or restore a backup, where the Backup page is, that a backup is one passphrase-protected file (at least 12 characters, not recoverable) that carries the key, what a restore checks before it changes anything, how the pre-update snapshots differ, and what a backup does not protect. It also says that an upload waiting for a decision, rejected or removed is not used in answers, and describes the speed line under an answer (#288).
