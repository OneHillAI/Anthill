**Web answers are easier for a small model to get right.** A web answer is followed by real links to the pages the model was given (those the answer does not already cite), the model is told today's date, a news question reads articles and not topic pages when it can, and the official site of a well-known project comes first for a "latest version" question. When you ask for today's headlines and only front pages and topic pages come back, the app says so plainly and lists those pages instead of asking the model, which could make headlines up.
