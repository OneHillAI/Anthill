**Memory and speed estimates for local models are more accurate.** The Apple chip lookup now matches the exact chip, so an M1 Pro, M2 Max or M5 Max no longer gets the base chip's memory speed, and chips sold with two GPU sizes are told apart. Anthill can also work out a model's cache memory from the model's own layers and attention heads, including sliding-window and hybrid models, and report weight, allocated, resident and peak memory with each marked estimated or measured. A new speed estimate for dense models is marked experimental. The picker's speed rule itself is unchanged, but it now reads the exact memory speed, so its "too slow" verdict can change on the chips that were wrong before (M1 Pro, M2 Max, M5 Max and similar).
