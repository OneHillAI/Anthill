**Tasks now run on a model that cannot use tools.** On a small model without tool support, such as gemma3:4b, every task failed at once with a technical error. Such a task now answers from its description and attached context, the result starts with a plain note that no tools were used, and the run is marked for your review and you are told, so a task that needed to act is never reported as a clean success. The New task dialog says so before you start one. In Chat, a deep question no longer quietly switches to the agent on such a model. Models that support tools work as before.
