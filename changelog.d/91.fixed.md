**Task actions say what they do, and only appear when you can use them.** Each task row shows only the actions you may use, named with the task. A cancelled task now shows Reactivate instead of Run now, and Run now no longer brings it back by accident. Reactivate turns the schedule back on without running anything: work that fell due while the task was cancelled is skipped, and follow-ups queued before the cancel wait for the next scheduled run. Cancelling asks first and says it stops future runs, keeps the history and does not interrupt a run already in progress.
