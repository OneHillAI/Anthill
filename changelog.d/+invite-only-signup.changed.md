**Sign-up is by invitation on a shared server.** When Anthill is reachable by other people (the container, `anthill web`, or any server with Remote access on), only the first account can be created freely. Everyone else joins by invitation, and the install owner can open sign-up again from the Remote access page. The install owner, the recorded account (the first sign-up, unless handed on or set from the host), cannot be demoted, deactivated or reset by anyone else, can be handed on, and can be set from the host with `anthill owner set`. The desktop app on its own machine keeps its open sign-up. If you run `anthill web` for yourself on your own machine, set `ANTHILL_LOCAL_ONLY=1`. **If you installed the macOS auto-start agent, run `make autostart` again after upgrading** so it picks up the new setting.
