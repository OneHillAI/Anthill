The `asdd/review` status no longer turns red when the only objection comes from the adversarial design pass: if the code, security, spec and impact lenses are all clean and the review ran live, the status stays green with a description that says only the design pass recommended changes, and the full objection is still posted in the review comment. A real finding (a security block, a concern or warning in another lens, a block anywhere, or a review that did not run live) keeps its failure. A human still decides.
