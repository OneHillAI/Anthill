**The model list now sizes small models by a measured rule instead of a guess.** For models up to about 10 GB the app now uses how much memory they really take, so a model that was labelled as fitting a 16 GB Mac comfortably (Qwen3.5 9B, Gemma 4 E4B) is now labelled tight, Gemma 4 12B is no longer offered there, and an 8 GB Mac is suggested a 4B model instead of a 2B one.
