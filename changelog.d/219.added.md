**Model calls now record how long they took and how much of the prompt was reused.** Every call to Ollama or an OpenAI-compatible model, streamed or not, keeps its prompt and cached token counts, prefill and generation times, load time, time to the first word and window size. The chat answer shows one muted line with the first-word time and tokens per second, and the numbers are stored with the Metrics row (numbers only, never text). Figures an engine does not report stay empty rather than 0.
