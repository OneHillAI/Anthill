**The Google Drive connector tile no longer claims more than it does.** It was listed as verified and as a source for importing documents, but it has never been tested end to end, its server is archived upstream, and it can only search file names: it has no way to read a document. The tile now says so, is marked community, and no longer appears in the import-from-a-service pickers. Importing from Drive is a separate piece of work.
