**The packaged app can verify and refresh the signed model catalog again.** The pinned dependency list the desktop build installs from had drifted: it was missing `sigstore`, which checks that the catalog came from our publishing workflow, so every refresh in the packaged app was refused. It is regenerated, and also drops 36 packages the app no longer uses (`torch`, the CUDA wheels and others), so builds download and check less. Checking the signature now fetches Sigstore's public trust data over HTTPS (tuf-repo-cdn.sigstore.dev) during a catalog refresh and caches it; no user data is sent, and with no connection the refresh fails safely and keeps the current catalog.
