**The desktop app opens filling the screen, then remembers its size.** The first time you open Anthill the
window fills the screen. After that it reopens the way you left it: the same size and place, maximized or not,
and a window saved on a bigger screen is brought back inside the one you have now. Nothing shows before the
app is ready. Tested on the Mac app; the Windows and Linux builds get the same change and have not been tested yet.
