**The Thinking button now says when your model cannot think.** Some models (Gemma and Mistral, for example) have no thinking mode, so "Thinking on" and "Thinking off" gave the same answer at the same speed, and the button still looked like a choice. Now the chat asks your local model what it can do. If it cannot think, the button reads "No thinking mode", is greyed out and does nothing, and its tooltip names the model. With a model that does think (Qwen, for example) the button works as before, and so it does for a cloud or organisation model, where Anthill cannot tell.
