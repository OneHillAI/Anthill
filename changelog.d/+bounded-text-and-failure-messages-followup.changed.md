**The admin connection checks and the model catalog refresh now show a plain message when they fail.** Testing the AWS, training, cloud key or mailbox connection, connecting a model server, listing its models and refreshing the model catalog each say what went wrong in plain words, and the mailbox status written in the background uses the same words. For a failed connection the server log records only the kind of error, never its text or the address.
