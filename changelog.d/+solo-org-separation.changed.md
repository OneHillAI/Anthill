**A Solo account is now strictly separate from an Org account.** Org-only pages (people, organisation settings and cloud, integrations such as Slack and Discord, agent access and the org wiki) return 404 for a Solo account instead of only being hidden from the menu. A Solo account that connects its own cloud endpoint stays Solo: it gets no Org chat, Org wiki scope, organisation agents or invites, and its own chats, project chats and personal wiki keep running on that endpoint. An Org account is unchanged. See `docs/specs/solo-org-separation.md` for the route table. Install-level host controls (open sign-up, install-owner transfer, remote access, the Mac appliance) stay with the install owner, and a Solo account's "use the cloud model" turn now runs on its own endpoint with its own wiki and personal context instead of the organisation plane.
