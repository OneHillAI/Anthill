**A Solo account is now strictly separate from an Org account.** Org-only pages (people, organisation settings and cloud, integrations such as Slack and Discord, remote access, agent access and the org wiki) return 404 for a Solo account instead of only being hidden from the menu. A Solo account that connects its own cloud endpoint stays Solo: it gets no Org chat, Org wiki scope, organisation agents or invites, and its own chats, project chats and personal wiki keep running on that endpoint. An Org account is unchanged. See `docs/specs/solo-org-separation.md` for the route table.
