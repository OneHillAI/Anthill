**`anthill knowledge inventory --apply` now keeps a page's permissions and leaves symbolic links alone.** Before, applying records rewrote each page through a temporary file, so a restricted page (for example 0600) came out with default permissions and a page that was a symbolic link was replaced by a regular file; undo did not put either back. Apply and undo now keep a page's permissions, and a symbolic link is skipped and reported. A dry run also reads the database read-only. No page text was ever lost.
