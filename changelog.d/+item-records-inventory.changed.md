**Every page and every kept original now carries a small record, and there is a command to bring existing wikis up to date.** The record holds an id, where the item lives, who wrote it, whether it has been checked, a version and what it was made from. It sits in the page's front matter (for an original, in a file under `records/`), so it travels with the file. Nothing you see in answers changes yet. `anthill knowledge inventory` reports what each wiki holds, including originals and texts left over from uploads that were held or rejected; it only reads. Add `--apply` to give existing items their records: it makes a backup first, never changes a page's text, and `--undo` puts everything back.
