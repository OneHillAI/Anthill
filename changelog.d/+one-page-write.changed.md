**A page is saved whole, and the text it replaces is kept.** Saving a page now replaces the file in one step, so a crash cannot leave half a page, and the version it replaces is kept in the wiki's `history` folder. A save made from an out-of-date copy of the page is refused and the edit screen says so, keeping the text you typed. A page changed in a text editor outside Anthill is noticed, recorded as your edit and not replaced by a model or an import; a model's change to such a page waits in the review queue.
