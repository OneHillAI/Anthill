**A multi-node hub no longer accepts promoted pages by default.** Before, a registered node could write a page straight into the hub's wiki, replacing any page with the same name, with nobody reviewing it. The hub has no review queue, so it now refuses promotions unless an operator sets `ANTHILL_MESH_PROMOTE_DIRECT=1`; then a node can only add a new page, which is marked as written by that node and not yet checked, and an existing page is never replaced. Single-node installs do not use this endpoint.
