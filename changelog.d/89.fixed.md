**Task results now read as formatted text.** The result page and run history showed a task's Markdown as raw punctuation. Headings, lists, tables, code and links now render. Because task output is written unattended and shown to everyone who can see the task, the page only allows plain text formatting: images become links, and forms, styles and anything that loads from another site are removed. A failed run stays plain text marked as an error, and "Save as snippet" still saves the original text.
