**Short notes are filed as they are.** A `.md` or `.txt` upload of at most 1,500 characters is no longer summarised: the page is the note itself, with its own heading as the title (or the file name when it has none), its text unchanged and no model call, so a tiny note is also not held up by a slow or missing model. The page view reads "The note as uploaded" instead of "Written by", the same file uploaded twice is still held as a duplicate, and a model upgrade never rewrites such a page. Larger notes, PDFs, Office files and images are summarised as before (#181).
