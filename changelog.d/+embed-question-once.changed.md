**Each chat question is now sent to the embedding model once, not four times.** For one question Anthill asked the embedding model for the same vector in four places: the answer cache lookup, memory recall, page retrieval and the cache write. The last few results are now kept for five minutes and reused, so a turn makes one call. Only questions and memory notes use this. Page embeddings are unchanged, and a failed call is never remembered. Answers are the same.
