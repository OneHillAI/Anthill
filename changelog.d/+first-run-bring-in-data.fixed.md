**A new desktop install can bring in an earlier copy's account.** A copy started from a project folder (`start.sh`, `make alpha`) keeps its data there, so the downloaded app found no account and offered only "Get started". The first-run page now has "Already used Anthill on this Mac? Bring in your account": give it the project folder and it copies the database, wikis, files, skills and saved keys into the app, leaves the old folder untouched, and sends you to sign-in. It works only on an install with no organisation, from the machine itself, and never overwrites anything already there. The page also says where the app keeps its data.
