**Each organisation has its own org wiki.** On a server with more than one organisation, the org wiki is now stored per organisation. An install with a single organisation keeps its pages where they are. If several organisations shared the old org wiki, it stays with the organisation that owns it, the others start with an empty one, and the owner is told on the organisation wiki page. Nothing is moved or deleted. Backups include the new `org-wikis` folder.
