**A Solo account can now find Backup.** Settings, on the This device tab, has a Backup card with a "Back up and restore" link. Before, the only links to the Backup page were on organisation pages, and the desktop app has no address bar, so a Solo Mac user could not reach it. A backup is one passphrase-protected file that carries your key, so it is the way back if this Mac's saved key is lost (#301).
