**A fine-tune that Ollama cannot register is now reported before it is trained.** From version 0.34.1 Ollama refuses to register an adapter, so a model trained for an organisation (not the on-device Mac path) could not be used, and the failure only appeared after training, as a general error. Now the run stops at the start with a plain note saying that this Ollama does not accept adapters, no training time is spent, and the registration step also looks for the engine where the app keeps it instead of only on the command path.
