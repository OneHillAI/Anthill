**Bare catalog tags (e.g. `qwen3.6`) now match Ollama's `:latest` suffix in routing and the model picker (#168).** `TaskRouter.pick()` and the web model picker/pull endpoints treat bare tags (`<tag>`) and `<tag>:latest` from `/api/tags` as matching and include `qwen3.6` in router preferences, preventing chat from falling back to `qwen2.5:3b` (404) when a bare catalog model is selected.
