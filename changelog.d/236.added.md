**A reference-machine speed scoreboard for developers.** A new tool, `tools/bench/run_scoreboard.py`, measures a local Ollama under a fixed protocol (decode and prefill at 0 and about 4,000 tokens, a fixed wiki prompt cold and warm, cold load, memory and swap-outs) and writes one result file per machine per release to `benchmarks/scoreboard/`, with the Ollama version, model digests and power state. `compare_scoreboard.py` flags any median that got worse by more than 15%. It never pulls or deletes a model, and refuses to run on battery. Nothing changes for users; the first result, for an M4 16 GB, is committed.
