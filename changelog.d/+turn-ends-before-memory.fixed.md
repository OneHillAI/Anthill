**A chat turn now ends when the answer ends.** Every few exchanges Anthill extracts durable memory from the conversation, which is a full call to your model. It ran before the end of the reply was signalled, so after the last word the page kept showing the Stop button, held back any follow-up you typed (it was queued, not sent) and did not finish the answer, and the whole server was blocked for the length of the call. It now runs after the turn has ended, on its own thread. What is remembered is unchanged. A question asked immediately afterwards can still wait behind that call on a single local model, as before, but no longer before the answer is shown as complete.
