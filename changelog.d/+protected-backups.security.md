**Backups are now one passphrase-protected file that carries the key.** The whole backup is encrypted, so it shows nothing without the passphrase (at least 12 characters, and it cannot be recovered). A restore checks the whole file, and that its key opens every saved password in it, before it changes anything, and puts everything back if it fails. Model files and secrets.env are not included, snapshots carry no key, and older plain backups still restore with a warning.
