**Stricter first-run setup and mesh access.** On a server that listens beyond the local machine, the first account now needs a setup token printed in the server console (set `ANTHILL_SETUP_TOKEN` to choose it). The orchestrator's read routes and the node agent's chat API now require the mesh token from other machines, and `anthill serve` will not listen beyond loopback without `ANTHILL_MESH_TOKEN`. With no mail server, a password-reset link is shown on the page only to a request from the machine itself on a server nobody else can reach; otherwise it is written to the console. The desktop app and servers that listen on the local machine only are unchanged.
