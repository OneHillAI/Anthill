**The answer panel, the Removed list and the edit page are easier to read.** "What this answer was given" now takes the full width under an answer instead of being squeezed beside the buttons. The Files and Removed lists show the name you uploaded a file under, not the stored name. After Remove, Restore or Delete the message appears above the Files list, "Delete now" is a red button that asks first, and the confirmation names pages by title and says plainly which pages stay. The edit page has a green Save button and a clear notice that the earlier text is not kept, and a page shows Edit and Remove in one row.
