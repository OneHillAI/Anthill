**Chat answers can no longer load content from other sites or change the page.** An answer that included text from the web or a document could carry an image from another site, and that image would load, with its address, as soon as the answer was shown. Forms, buttons and styles in an answer could also alter the page. Chat now shows text formatting and images from Anthill itself only. A remote image appears as a link instead and loads only if you click it.
