**Settings model card shows the model's own size.** "On this device" on the Your machine card used to show the size of the whole Ollama models folder (4.6 GB for a 1.9 GB `qwen2.5:3b`, because it counted other models and leftover downloads). It now shows the configured model's size from Ollama, and the folder total on its own "Models on disk" line when it is larger. If Ollama cannot be reached or the model is not installed, no size is shown (#160).
