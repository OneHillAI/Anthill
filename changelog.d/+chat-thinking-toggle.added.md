**Thinking and web search, per chat.** Some models think before they answer, and you can wait ten seconds or more for the first word. A new Thinking button under the message box turns that off for a chat, and Options does the same for web search. Both now have a default in Settings (Thinking under Model, Web access under Privacy), and each chat can differ from it. Thinking only affects models running on this machine. Both are on by default for new accounts. Web search is on because most questions are about live information; it sends the text of the question to a search provider, so you can turn it off for one chat or for all. A question that searches the web shows its answer when it is complete, and Thinking off makes that wait shorter. The first time you open Chat, Agents or Tasks, a short notice shows the defaults and lets you change them.
