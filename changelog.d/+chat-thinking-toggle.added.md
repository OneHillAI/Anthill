**Thinking and web search, per chat.** Some models think before they answer, and you can wait ten seconds or more for the first word. A new Thinking button under the message box turns that off for a chat, and Options does the same for web search. Both now have a default in Settings (Thinking under Model, Web access under Privacy), and each chat can differ from it. Thinking only affects models running on this machine. Both are off by default for new accounts, so answers start quickly: on a 16 GB Mac with a 9B model, a plain question showed its first word after about 3 seconds with Thinking off and about 30 seconds with it on. Web search sends the text of the question to a search provider, so turn it on only when you want it, for one chat or for all. With it off, nothing is searched on the web, not even a question that clearly needs live information, unless you ask for it in plain words as a follow-up ("check the web"). Accounts that already exist keep the values they have. The first time you open Chat, Agents or Tasks, a short notice shows the defaults and lets you change them.
