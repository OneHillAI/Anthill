**The desktop app no longer fails to start when Ollama is already running.** The app set up its database in two places at once, and on a Mac where Ollama was found at once one of them could use the database before set-up had finished, which stopped the start-up with "NoneType is not callable". Database set-up now finishes before anything uses it, and a set-up that fails is tried again on the next call.
