**A model you fine-tune on a separate GPU machine can be made to work with the newer engine.** After training, the machine can merge the learned changes into the model and send it back in a form every engine accepts, so registering it no longer fails on engine 0.34.1 and later. This starts working once the training machine's image is rebuilt and the owner switches it on; until then nothing changes. Fine-tuning on an Apple Silicon Mac is unchanged.
