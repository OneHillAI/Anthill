**An Ollama on another machine is no longer reported as "answered on this device".** The local-or-remote badge, the audit log and the escalation gates used to treat every Ollama as local, whatever address it was set to. They now look at the address: only this machine (localhost, loopback, or the Docker host name) counts as local, and an Ollama on a LAN box or another address is shown as remote. A setup that reaches Ollama through a Docker container name now reads as remote too.
