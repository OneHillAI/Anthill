**An Ollama on another machine is now reported as remote and protected like any remote endpoint.** The local-or-remote badge, the audit log and the escalation offers used to treat every Ollama as local, whatever address it was set to, and its text was sent as written. Now only this machine (localhost, loopback, or the Docker host name) counts as local. For an Ollama on a LAN box or another address, the text is redacted before it is sent, images are not sent, the reply is restored, and the answer shows the remote badge. A setup that reaches Ollama through a Docker container name now reads as remote too, and image questions through a remote Ollama are refused with a note.
