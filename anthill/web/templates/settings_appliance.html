Make it always-on

A guided installer is on the way; until then, these three steps turn this Mac into an appliance. Run them once.

1. Run as a background service (LaunchAgent)

Starts Anthill at login and restarts it if it ever stops. It must be a LaunchAgent (in your login session), not a system daemon, so the GPU stays available.

Download {{ label }}.plist 
{{ plist }}

Then load it:

mkdir -p ~/Library/LaunchAgents
mv ~/Downloads/{{ label }}.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/{{ label }}.plist

2. Never sleep, auto-recover from power loss

Or set the same under System Settings -> Energy (prevent sleeping, start up after a power failure, wake for network).

3. Auto-login (required for the GPU)

System Settings -> Users & Groups -> Login Options -> Automatic login = the user this server runs as. A logged-in session is what gives Ollama the Apple GPU after every reboot.

FileVault note Disk encryption (FileVault) blocks unattended auto-login - the disk asks for a password at the first boot. For an unattended appliance, either leave FileVault off and rely on physical security, or set up fdesetup automatic unlock. Your call.
