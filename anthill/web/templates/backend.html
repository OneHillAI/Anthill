Making it reachable by everyone

Because the wiki is served live from this host, your team always sees the latest - but only while this machine is on and reachable. For teammates on other machines or off the office network, expose this host securely (a reverse proxy with TLS and/or a VPN). To keep it reachable "anytime," run it on a machine that stays up - an on-prem server or a persistent VM in your own cloud / VPC. See the Setup guide ("Where to run Anthill") for the deployment details.

Connected nodes: per-device node registration and a live fleet view are on the roadmap. Today your team reaches the backend through the dashboard URL above.
