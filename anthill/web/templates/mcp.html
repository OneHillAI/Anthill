Connect tools over MCP

MCP (Model Context Protocol) is the standard way agents reach external tools and data. Connect any MCP server here instead of hand-writing a connector. A new server stays pending until you test and approve it - only approved servers' tools reach agents, and every call is scope-gated (the mcp scope) and audited.
