Restore from a backup

Replaces the current database, wiki, files and skills with what is in the backup, and puts its key in place of this install's key. Anthill checks the whole file first, and that its key opens every saved password in it. With the wrong passphrase, or a damaged or cut-short file, it stops and nothing is changed. Only then does it keep a safety copy of the current data, so a mistaken restore can be undone, and replace it. Restart Anthill afterwards: the running copy still holds the old database in memory. An older plain backup (.tar.gz) is accepted too if it carries a key, and the page will say it was not protected; enter a passphrase for the safety copy.
