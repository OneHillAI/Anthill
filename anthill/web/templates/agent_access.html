What is this page?

When Anthill does work on its own - answering in agent mode, or running a scheduled task - it acts under a named agent identity, not as you. Each identity has a fixed set of scopes (what it's allowed to touch). This is what makes automation safe and auditable:

  • Attributable - every action is logged against the identity that did it (see the audit table below).
  • Least-privilege - an identity can only use tools inside its scopes; anything else is blocked.
  • Revocable - disable an identity and it stops acting immediately.

Risky actions (like sending an email) still ask for your per-action approval on top of scopes. You normally don't need to create identities by hand - they're made automatically the first time chat-agent mode or the scheduler runs. Create one manually only to pre-set its scopes.

Identities

Type labels what kind of automation this identity governs (it's how the system attributes actions to the right identity):

  • chat - the agent that runs when you turn on Agent mode in chat.
  • scheduler - the background runner that executes your scheduled/event tasks.
  • custom - your own agent, for anything else you wire up.

New identities start with least-privilege scopes (web, wiki, files, docs). Grant connector scopes (slack, notion, jira, gdrive, msgraph, email) on the identity's card below as needed.
