Anthill help
Ask how to do something ("what is agent mode?"), request a feature ("I wish Anthill could…"), report a bug, or just ask a question. I can file feature requests and bugs for the team.

Install Anthill

Recommended - the Mac app. Build the installer with make dmg, open Anthill.dmg, and drag Anthill into Applications. It installs to /Applications and launches with no Terminal window.

Browser install is quicker but Chrome-managed: it lands in ~/Applications/Chrome Apps/ (your user folder, not /Applications) and only works while the local server is running.

Any element with data-confirm="Question?" shows this in-DOM confirm first; on Confirm the element's real action (form submit, link, or its own onclick) proceeds. window.anthillConfirm(msg) -> Promise is also exposed for the few in-script call sites. #}
